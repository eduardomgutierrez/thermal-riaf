# radproc thermal interface

`radproc` calculates radiation from a radial accretion-flow model. The supported
collaborator-facing entry point is the top-level `riaf_pipeline.py`; it selects
only thermal synchrotron, electron/ion bremsstrahlung, and thermal Comptonization
and disables the legacy nonthermal modules.

The C++ program expects `parameters.json` and one of these profile formats in its
working directory:

- `adafFile.txt` plus `adafParameters.txt`, generated by the bundled Python RIAF
  solver; or
- an external radial profile selected with `readPrecomputedADAF`.

For direct development builds:

```bash
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build --parallel
```

The executable is `build/src/adaf/adaf`. Run it from a prepared spectrum folder,
not from the source directory. Named keys under `thermal.processes` are preferred;
the older `thermal.processNumber` keys remain supported for compatibility.

See the top-level README for dependencies, the one-command workflow, model
configuration, and the external-profile schema.
